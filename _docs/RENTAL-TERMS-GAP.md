# 렌탈 약관 대조 — 우리 시스템 부족 조건 점검

2026-08-01 · 대조 기준: 메리츠캐피탈 자동차렌탈(대여) 약관 2025.11 (사용자 제공)
※ 타사 약관은 구조 참조용 — 문구 복제 금지(저작권 명시됨). 우리 약관은 /admin/contract-terms 에서 자체 작성.

## A. 이미 커버됨 (견적 엔진·기준표에 존재)

| 약관 조항 | 우리 시스템 |
|---|---|
| 보증금·선납 렌트료 (4·5조) | 견적 입력 deposit/upfront_months + 할인율(DEPOSIT 0.4%/PREPAYMENT 0.5%) |
| 운전자 연령 할증 (6조·보험조건) | driver_age: 26세이상 표준 / 21세이상 +40% / 전연령 +65% — 약관과 동일 구조 |
| 사고 건당 자기부담금 (8조⑥) | DEDUCTIBLE_AMOUNT 500,000 (실증권과 일치: 대차 50만/기타 100만 구조는 보험조건) |

| 렌트료 일할 (3조②) | (월×12)/365 방식 — 정산 로직에 동형 존재 |

## C. 설정/계약 조건 필드 부족 — 계약서·운영 정책

- **운전자 범위**: 본인/배우자/직계가족/임직원(4대보험·급여 3개월 증빙), 추가운전자 최대 2인, 임직원 전용 보험 여부 — 계약 조건 필드 없음
- **정비 상품 티어**: Basic/순회정비(주기 선택)/정비제외 + 대차서비스 포함 여부 — 우리 정비 원가는 단일값. 티어별 원가 차등하면 견적 경쟁력·마진 관리에 유리
- **보증금 대체**: 이행(지급)보증보험증권 허용 여부
- **보증금·선납 충당 순서**: 비용→자기부담금→이자→렌트료→중도해지수수료 (분쟁 방지용 명문화)
- **승계**: 승계 기준 + 승계 수수료
- **해지 절차**: 고객 해지 5일 전 통보, 등록 전 해지 시 실비 정산 목록(차량대금·탁송·보험료·등록비·공채·**차고지이용료·증차비용**) — 증차(영업용 번호) 비용은 우리 취득 부대비에도 미반영
- **사고 세칙**: 손상부위 기준 건당 산정, 미신고 이탈 시 200만 초과 전액 부담, 수리 보증 90일, 지정 공장 원칙
- **금지행위/보험 면책 목록** (7조③·24조): 우리 계약서 약관에 동등 수준 명시 필요
