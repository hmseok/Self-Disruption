## 1. 현재 엔진이 이미 계산하는 것 (lib/quote-cost.ts + rent-calc-engine.ts)

입력: 매입가 · 브랜드/모델 · 연료 · 배기량 · 기간(24/36/48/60) · 연간 km · 반납/인수 (+보증금·선납)
기준 데이터: `/db/pricing-standards` (요금 기준표 — 감가율/금리/보험/정비/마진 기본값, DB 단일 소스)

출력 (`QuoteCostResult`):
- **7대 원가 (월)**: 감가 / 금융 / 보험 / 정비 / 세금·검사 / 리스크 / 간접비 − 보증금 할인 = `cost_breakdown.total`
- **적정 렌트료** `suggested_rent(_with_vat)` = 원가 + 기본 마진
- **판단 지표**: 마진율 % · 연 IRR % · 회수 개월(breakeven_months) · 경쟁력 지수(시장 평균 대비) · 렌트료/매입가 비율
- **산출 근거**: 항목별 공식·출처(cost_detail) + 시장 표준가 비교(market_reference)

## 2. 수익/손실의 경계 — 이미 존재하는 수치로 정의 가능

**손익분기 렌트료 = `cost_breakdown.total` (월 원가 합계, VAT 별도).**
이 아래로 계약하면 그 계약은 구조적으로 적자다. 즉:

```
손실 영역     <  원가(total)  <  방어 영역  <  적정가(suggested)  <  우위 영역
                 ↑ 손익분기선                  ↑ 기본 마진 반영
```

## 3. 고객 인입 → 결과 구성 (견적 작성 화면 리뉴얼 때 구현할 것)

1. **인입 입력 최소화**: 고객명/연락처 + 차종(카탈로그 선택 or 보유차) + 기간 + 연간 km → 나머지는 기준표 기본값
2. **결과는 3구성 비교로 제시** (한 번 계산에 기간·보증금 시나리오 3개):
   - 예: 36개월/보증금 0 · 48개월/보증금 300 · 60개월/선납 1회 — 각각 월렌트료·마진율·IRR
3. **경계 게이지 표시**: 협상가 입력란 + 게이지(빨강: 원가 미만 = 손실 / 노랑: 원가~적정가 = 저마진 / 초록: 적정가 이상). `acquisition_total` 이 협상가 마진 재산출용으로 이미 응답에 포함됨.
4. **가드레일**: 원가 미만 저장 시 경고(사유 입력) — 손실 계약은 만들 수 없게 하는 게 아니라, 알고 만들게 한다.
5. **정확도 유지 루프**: 기준표(pricing-standards)가 곧 경계의 정확도 — 보험료·금리 실측치가 바뀌면 기준표를 갱신 (분기 1회 점검 권장).
